# Execution plans

Use a versioned execution plan for complex work that is likely to span multiple sessions, agents, or substantial implementation phases.

- Active plans live in `active/`.
- Completed plans worth retaining move to `completed/`.
- Small or obvious tasks do not need a plan file.

A useful plan records the goal, constraints, accepted decisions, implementation slices, validation, progress, and unresolved questions. It should enable a fresh agent session to continue without relying on chat history.
